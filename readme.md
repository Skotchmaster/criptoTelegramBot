# Crypto Candles Telegram Bot

Бот анализирует свечи топ-100 криптовалют и выдаёт короткую сводку (RSI, SMA-кроссы, свечные паттерны) по выбранному таймфрейму.

## Быстрый старт

1) Python 3.11+  
2) `cp .env.example .env` и впишите `BOT_TOKEN`  
3) `pip install -r requirements.txt`  
4) `python -m bot.main`

## Как это работает

- **Топ-100** берётся из публичного API CoinGecko.  
- **Свечи** берутся из публичного API Binance (пара `<SYMBOL>USDT`). Некоторые топ-монеты могут отсутствовать на Binance — в этом случае бот сообщит об этом.
- **Таймфреймы**: `1h`, `4h`, `1d` (лимит данных ~200–400 свечей).
- **Сигналы**: RSI(14), SMA20/50, Golden/Death cross, базовые паттерны (Doji, Hammer, Shooting Star, Bullish/Bearish Engulfing).

## Расширение

- Добавляйте индикаторы в `bot/services/analysis.py`.
- Формат ответа — в `bot/services/formatter.py`.
- UX (кнопки/пагинация) — `bot/keyboards.py`.
- Источники данных — `bot/services/market.py` (можно прикрутить ccxt или другие биржи).
- Кэш и лимитирование — добавить в `services/cache.py` или обернуть вызовы в мемоизацию.

## Надёжность

- Таймауты и ошибки внешних API аккуратно обрабатываются.
- Логирование — в stdout (можно подключить Sentry и т.п.).
- Один общий `aiohttp.ClientSession` на приложение.

## Дисклеймер

Это **не** финансовый совет. Используйте результаты как информационную справку.
